## Схема процесса совместной работы на GitHub

Ниже приведена диаграмма последовательности (sequence diagram), показывающая взаимодействие участников при совместной разработке проекта на GitHub.

```mermaid
sequenceDiagram
    participant M as Участник
    participant GH as GitHub
    participant O as Владелец проекта

    O->>GH: Создаёт организацию и репозиторий
    GH-->>O: Репозиторий готов к работе
    M->>GH: Делает fork репозитория
    M->>M: Создаёт ветку для новой функции
    M->>GH: Выполняет commit изменений
    M->>GH: Отправляет Pull Request
    O->>GH: Проверяет и одобряет Pull Request
    GH-->>M: Уведомление об одобрении
    M->>GH: Выполняет merge в основную ветку
    GH-->>O: Репозиторий обновлён
```

Схема иллюстрирует основные шаги взаимодействия между участником, владельцем проекта и GitHub в процессе совместной разработки программного обеспечения.
